🚗 Locadora de Veículos — Refatoração de Banco de Dados
📌 Sobre o projeto
Projeto acadêmico desenvolvido para o exercício de Sprint Ágil de Refatoração de Banco de Dados.
O objetivo é melhorar a organização e o desempenho de um banco de dados de uma locadora de veículos, substituindo uma estrutura que concentra diversas informações em uma única tabela por um modelo relacional normalizado.
🎯 Objetivos
Separar informações por entidades.
Reduzir redundâncias.
Implementar chaves primárias e estrangeiras.
Criar índices para otimizar consultas.
Testar operações e relacionamentos no SQLite.
